## 🎮 Overview

Cathedral Assets Optimizer processes mod files in bulk, compressing textures to DXT, optimising NIF meshes, converting animations, and resizing BSAs.

Whether you're a newcomer or a veteran, Cathedral Assets Optimizer provides the tools you need to get the most out of your gaming mods experience. Designed for Windows and macOS, it delivers a seamless, high-performance workflow.

## ✨ Key Features

| Feature | Description |
|---|---|
| **Texture Compression** | Batch compress PNG and TGA textures to BC7 or DXT formats |
| **Mesh Optimizer** | Fix and optimise NIF meshes for maximum engine compatibility |
| **BSA Packer** | Pack loose files into BSA archives or unpack existing ones |
| **Profile System** | Save processing settings as named profiles for reuse |
